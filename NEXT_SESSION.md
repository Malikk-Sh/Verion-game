## 2. Что это за проект

Мобильная браузерная одиночная survival-sandbox на **Three.js / WebGL2**, landscape, русский интерфейс: выживание (кислород), добыча, производство, терраформирование, путешествия между планетами. Без сервера и обязательного аккаунта; сохранения — IndexedDB + экспорт/импорт JSON; localStorage только для настроек.

## 5. Команды и проверки

```sh
npm ci
npm run dev            # vite, http://localhost:5173
npm test               # 8 тестов контроллера/мира (node --test + tsx)
npm run build          # tsc + vite + автономный preview/vireon-verdana-b4.html
VIREON_CHROMIUM_PATH=/путь/к/chromium npm run verify:browser   # 26 браузерных проверок
```

- `verify:browser` идёт в Chromium с **программным** WebGL (SwiftShader, <1 FPS) и занимает ~25 минут. Запускать в фоне с логом, **сначала `npm run build`** (иначе проверяется устаревший автономный файл) и не менять файлы во время прогона. Это проверка корректности, **не производительности**.
- Стенд крупных планов: `tools/scene-review.html?view=capsule|interior|cave|grass|valley|ice|ore|door|flank|berth|rack|copper|vista|canyon|crater` (`&night` — ночь). Удобно снимать скриншоты Playwright'ом и смотреть глазами перед отдачей пользователю.
- В программном WebGL клики Playwright иногда зависают на «ожидании навигации» — для служебных скриптов надёжнее `page.$eval(sel, e => e.click())`.
- Числа производительности обещать только после замеров на физических устройствах (`08_BALANCE_QA.md` §5: три устройства, p95 ≤ 33,3 мс на Low).

## 6. Что делать дальше

Визуальный этап принят. Дальше — игровые системы строго по `docs/spec/08_BALANCE_QA.md` §6:

1. **Основа** — управление, фиксированный clock активного времени, один регион, добыча/коллизии, надёжная запись и экспорт/импорт (IndexedDB, атомарные ревизии, lease между вкладками — `07_TECHNICAL.md` §3, §6, §9). Пройти **V17–V20** на минимальном мире.

3. **Производство** — сети, электричество, сита/пресс, ферма, симуляция покинутых миров. V07–V10, сцены нагрузки A/B.
4. **Путешествие** — ракета/посадка, Нива, велит, jetpack/астероид, враги, **ровер** (для него и увеличен мир). V11–V14, C/D.

6. **Полировка Core** — обучение, доступность, баланс/графика/звук, реальные устройства.

## 7. Неприкосновенные правила (кратко, полная версия — GDD §3)

До двух баллонов; холод не ускоряет расход O₂; капсула не производит газ. Планетарный результат не откатывается. Руды конечны. Рельеф плавный, блочные раскопки локальны. Враги появляются в темноте; свет мешает появлению; солнце наносит урон. Потерянный груз не исчезает. Все миры живут только в активном времени; пауза/скрытие останавливают всё. IndexedDB + экспорт; localStorage только настройки. Не добавлять: мультиплеер, аккаунт, сервер, офлайн-производство, полную воксельную разборку, течение воды по шахтам. Не расширять состав первой версии молча.
