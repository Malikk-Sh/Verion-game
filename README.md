# Vireon

Мобильная браузерная одиночная песочница: выживание, шахты, производство, терраформирование и путешествия между планетами. Three.js/WebGL, landscape, русский интерфейс.

**28 сентября 2026: полный GDD 1.0, исходный баланс B0.** 195 определений предметов, 213 рецептов, игровые правила и техническая спецификация. Документация служит основой реализации. Есть визуальный образец B4 и этап S1 «Основа» (добыча и сохранения); выживание, производство и замеры на физических телефонах ещё впереди.

**29 сентября: [Вердана B2](docs/prototypes/VERDANA_B2.md).** По замечаниям к B1 переработаны капсула с интерьером, скальный вход пещеры, камни, грунт и интерфейс. Травы примерно в пять раз меньше, она растёт пятнами и отдельными пучками. В меню добавлен полный экран. Ходьба, карта, день/ночь и мобильное управление работают; выживание и добыча ещё впереди.

**30 сентября: [Вердана B3](docs/prototypes/VERDANA_B3.md).** Визуальная переработка: плотный рельеф с тропами, снегом и гарью от посадки, кольцо гор, сколотые скалы, детализированная капсула и интерьер, небо со звёздами, тени и туман, процедурный звук, титульный экран и «пробуждение» в шлеме, новый футуристичный интерфейс и профили качества графики. FPS на телефоне ещё не измерен.

**30 сентября: [Вердана B4](docs/prototypes/VERDANA_B4.md).** По замечаниям к B3: мир 560×560 м вместо 160×160 (столовая гора, кратер, сухое русло, 12 мест), запечённые тени без «ползания» и дрожания, плавный бег под уклон, новая надпись на корпусе и новый интерьер капсулы, рудные выходы с прожилками на поверхности, меню настроек с титула (полный экран, качество, звук, покачивание, поле зрения). FPS на телефоне ещё не измерен.

**3 октября: [Вердана S1 — этап «Основа»](docs/prototypes/VERDANA_S1.md).** Первые игровые системы: единые игровые часы, конечная добыча железа, меди, камня и льда (удерживать «Добыть»), рюкзак на 24 слота, сохранение в браузере (IndexedDB, атомарные ревизии, защита от двух вкладок), экспорт и импорт файла `.vireon.json`. Проверки V17–V20 проходят в автотестах. FPS на телефоне не измерен.

**Продолжение работы:** новая сессия с ассистентом начинается с [NEXT_SESSION.md](NEXT_SESSION.md).

В PR #2 исправлены открытие импортированных миров, запись после восстановления повреждённой ревизии и сохранение текущей сессии при неудачном переключении мира. `npm test`: 28/28; сборка проходит. Браузерная проверка этих исправлений пока не выполнена — Chromium не удалось установить.

## Попробовать

Скачать [vireon-verdana-s1.html](preview/vireon-verdana-s1.html) и открыть в браузере. Это один автономный файл; на телефоне надёжнее использовать локальный сервер. GitHub показывает исходный код HTML, а не запускает игру. [Управление и проверки S1](docs/prototypes/VERDANA_S1.md); визуальные образцы B4, B3 и B2 сохранены для сравнения.

Для разработки: `npm ci`, затем `npm run dev`. Проверки: `npm test`, сборка: `npm run build`, браузер: `npm run verify:browser` и `npm run verify:s1` после установки Playwright Chromium.

**Играть:** [verion-game.vercel.app](https://verion-game.vercel.app/). Проект опубликован на Vercel из ветки `main`; требуется браузер с WebGL 2. [Подробности и ограничения проверки](docs/prototypes/VERDANA_B2.md#публикация).

## Статус решений

Пользователь принял рекомендуемые R1–R8 и разрешил самостоятельно закрыть остальные вопросы. Новый GDD различает прямые решения пользователя, делегированные решения и численный баланс, который ещё не проверен игрой. Повторные опросы старых развилок не нужны. Поправки пользователя имеют приоритет.

Первая версия: две планеты, один тип астероида и полный наземный цикл терраформирования. Орбитальная станция/торговля — Expansion 1; жаркая Пирра и позднее оборудование — Expansion 2. Большое описание расширений не делает их обязательной частью первого выпуска.

## Проверка проектных данных

```bash
python3 tools/build_design_catalog.py
python3 tools/validate_design.py
python3 tools/build_full_gdd.py
```

Скрипты не являются кодом игры. Они строят таблицы и проверяют ID/зависимости/некоторые расчёты. Игровая проходимость, геометрия и FPS проверяются будущим прототипом.
