# Vireon — память проекта

Мобильная браузерная survival-sandbox об исследовании планет, добыче, строительстве, терраформировании и космических экспедициях.

**Состояние на 28 сентября 2026:** проектирование, GDD редакции 0.14. Игрового кода и проверенного прототипа в этой передаче нет.

## Продолжение в новой сессии

1. Прочитать [контекст следующей сессии](docs/SESSION_CONTEXT.md).
2. Прочитать [GDD](docs/GDD_Vireon.md), особенно статусы в начале, §18 с открытыми решениями и соответствующие разделы механик.
3. Для референсов использовать [исследование Ad Astra](docs/research/Ad_Astra_Research_RU.md).

Для ИИ-ассистентов: [AGENTS.md](AGENTS.md).

Готовое сообщение для нового чата:

> Продолжаем проект Vireon из репозитория https://github.com/Malikk-Sh/Verion-game. Прочитай AGENTS.md, docs/SESSION_CONTEXT.md и docs/GDD_Vireon.md. Сохрани утверждённые решения. Подготовь цельный черновик оставшихся систем, начиная с терраформирования, и один сводный список до 10–15 важных вопросов с вариантами; предложения явно отделяй от согласованного. Числа и рецепты предложи таблицами. Не начинай заново серию мелких опросов. Обновляй документацию в этом репозитории.

## Документы и их статус

| Файл | Назначение |
| --- | --- |
| `docs/SESSION_CONTEXT.md` | Краткая память: принятые правила, последнее обсуждение, ограничения и следующий шаг |
| `docs/GDD_Vireon.md` | Полная спецификация/рабочее видение, открытые вопросы и журнал 13 циклов ответов |
| `docs/research/Ad_Astra_Research_RU.md` | Версионно привязанный разбор мода; его факты и предложения не являются автоматически правилами Vireon |
| `AGENTS.md` | Правила работы с проектом и порядок чтения |

Рабочее название в документах — **Vireon**; пользовательский репозиторий называется **Verion-game**. Имена сохранены как есть, переименование не согласовывалось.
