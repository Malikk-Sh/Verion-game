# Vireon

Мобильная браузерная одиночная песочница: выживание, шахты, производство, терраформирование и путешествия между планетами. Three.js/WebGL, landscape, русский интерфейс.

**28 сентября 2026: полный GDD 1.0, исходный баланс B0.** 195 определений предметов, 213 рецептов, игровые правила и техническая спецификация. Документация служит основой реализации. Уже есть визуальный образец B3; полные игровые системы и замеры на физических телефонах ещё впереди.

**29 сентября: [Вердана B2](docs/prototypes/VERDANA_B2.md).** По замечаниям к B1 переработаны капсула с интерьером, скальный вход пещеры, камни, грунт и интерфейс. Травы примерно в пять раз меньше, она растёт пятнами и отдельными пучками. В меню добавлен полный экран. Ходьба, карта, день/ночь и мобильное управление работают; выживание и добыча ещё впереди.

**30 сентября: [Вердана B3](docs/prototypes/VERDANA_B3.md).** Визуальная переработка: плотный рельеф с тропами, снегом и гарью от посадки, кольцо гор, сколотые скалы, детализированная капсула и интерьер, небо со звёздами, тени и туман, процедурный звук, титульный экран и «пробуждение» в шлеме, новый футуристичный интерфейс и профили качества графики. FPS на телефоне ещё не измерен.

## Попробовать

Скачать [vireon-verdana-b3.html](preview/vireon-verdana-b3.html) и открыть в браузере. Это один автономный файл; на телефоне надёжнее использовать локальный сервер. GitHub показывает исходный код HTML, а не запускает игру. [Управление и проверки B3](docs/prototypes/VERDANA_B3.md); B2 сохранён для сравнения.

Для разработки: `npm ci`, затем `npm run dev`. Проверки: `npm test`, сборка: `npm run build`, браузер: `npm run verify:browser` после установки Playwright Chromium.

**Играть:** [verion-game.vercel.app](https://verion-game.vercel.app/). Проект опубликован на Vercel из ветки `main`; требуется браузер с WebGL 2. [Подробности и ограничения проверки](docs/prototypes/VERDANA_B2.md#публикация).

## Статус решений

Пользователь принял рекомендуемые R1–R8 и разрешил самостоятельно закрыть остальные вопросы. Новый GDD различает прямые решения пользователя, делегированные решения и численный баланс, который ещё не проверен игрой. Повторные опросы старых развилок не нужны. Поправки пользователя имеют приоритет.

Первая версия: две планеты, один тип астероида и полный наземный цикл терраформирования. Орбитальная станция/торговля — Expansion 1; жаркая Пирра и позднее оборудование — Expansion 2. Большое описание расширений не делает их обязательной частью первого выпуска.

## Проверка проектных данных

```bash
python3 tools/build_design_catalog.py
python3 tools/validate_design.py
python3 tools/build_full_gdd.py
```

Скрипты не являются кодом игры. Они строят таблицы и проверяют ID/зависимости/некоторые расчёты. Игровая проходимость, геометрия и FPS проверяются будущим прототипом.
