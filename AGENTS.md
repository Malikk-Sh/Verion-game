Three.js/WebGL2, mobile-first landscape, одиночная игра, русский язык. IndexedDB для сохранений + экспорт/импорт JSON-файла; localStorage только настройки. Нет сервера/обязательного аккаунта, офлайн-прогресса, полной разборки планет или динамического затопления шахт. Покинутые миры работают только при активных игровых часах, без урона от мобов/погоды.

Первая версия: Вердана + Нива + один тип астероида + полный наземный путь. Станция и торговля после неё. Пирра — Expansion 2. Не увеличивать состав первой версии молча.
