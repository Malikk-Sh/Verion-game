# Вердана B4 — большой мир, тени, интерьер и настройки

30.09.2026. Продолжение B3 по замечаниям Малика к preview pull request #1. Это по-прежнему **визуальный образец Three.js**: выживания, добычи, ровера и сохранения мира нет. B3 сохранён как история (`VERDANA_B3.md`, `preview/vireon-verdana-b3.html`).

## Замечания и что сделано

| Замечание | Решение B4 |
| --- | --- |
| Надпись на корпусе капсулы разрезают рёбра и дверь | Текстура корпуса строится по граням восьмигранника: U пропорционально периметру, швы совпадают с рёбрами. Надписи «VE—01» и подписи стоят внутри граней 2 и 6, вне иллюминатора и панели; на корме — предупреждение, над дверью — «VE—01 · ШЛЮЗ», на косяках — шевроны. Рёбра только снаружи корпуса. |
| Плохой интерьер: плоские стены, песок в углу, чёрные конусы и белые клинья | Стойки опор и RCS-блоки больше не пробивают корпус внутрь. Новая обшивка панелями, восьмиугольный решётчатый пол, отбойник и поручень, потолочная световая панель и циан-кольцо, кабели, внутренние рамки двери и иллюминаторов. Койка с ящиками, скруглённым матрасом, подушкой, одеялом и ремнями, полка с лампой; консоль с наклонным экраном, клавиатурой и огнями; стойка баллонов с хомутами; шкафчик; стеллаж с кейсами, аптечкой и шлемом. Песок внутрь не заходит. |

| Дрожание теней на «высокой» | Тень привязана к текселю карты теней в пространстве света и не «плавает» при движении; фрустум смещён вперёд по взгляду. Высокая: 2048, ±60 м; стандарт: 1024, ±42 м. |
| Тени гор и скал «ползут» | Дальние тени больше не берутся из карты теней: при загрузке запекается карта видимости солнца (сетка 4 м) по рельефу, скальным формациям, шпилям и массиву пещеры. Её учитывают все материалы; ночью она отключается. Крупные краевые скалы в карту теней не пишутся, поэтому тени не появляются и не исчезают на границе. |
| Местность интереснее и в 3–4 раза больше | Мир **560×560 м** (−200…360 по X и Z) вместо 160×160 — в 3,5 раза шире. Долина прибытия сохранена в центре; вокруг — холмы и дикий рельеф, столовая гора (−105; 165), кратер (265; 255), сухое русло с крутым южным берегом, горная стена по краю. 84 скальные формации с коллизиями, 520 крупных камней и 2 600 камешков по миру. Новые места: «Сухое русло», «Столовая гора», «Кратер» — всего 12. Дальние места задуманы как цели для будущего ровера; самого ровера пока нет. |
| Настройки с главного экрана | На титуле кнопка «Настройки». Панель: полный экран, качество графики, звук, покачивание камеры (вкл./выкл.), поле зрения 60–95°, показатели сцены. Та же панель открывается из паузы. Всё сохраняется в `localStorage` (`vireon.settings`). При выключенном покачивании FOV не расширяется при беге. |
| Недочёты интерфейса | Убрана плашка прототипа из HUD, сильнее тень текста и контраст меток, подложка компаса и дистанции метки, метка цели не заезжает на верхнюю панель, панель настроек уплотнена на экранах 667×320, карта показывает весь мир (рельеф, изолинии 4 м, сетка 80 м, рамка долины, шкала 100 м) и дистанции в списке мест, показатели вынесены под задачу. |
| Медные прожилки висели в воздухе; переделать стартовые модели | Рудные выходы строятся функцией `oreOutcrop`: прожилки — копии граней самой глыбы с небольшим сдвигом по нормали, а не отдельные объекты, поэтому они лежат на поверхности. Добавлены кристаллы, пятна патины (медь) и ржавчины (железо), лежащие рядом обломки. Лёд — вмёрзшие плиты, наклонные осколки и крошка; трава убрана из ледяной низины. Описания мест переписаны честно: добывать ресурсы пока нельзя. |

## Рельеф и производительность

- Высота — одна функция `heightAt` (`src/world.ts`) для отрисовки, коллизий и контроллера; сетка 1 м строится лениво.
- Отрисовка (`src/terrain.ts`): блоки 80 м на грубой сетке 4 м плюс подгружаемые чанки 40 м на сетке 1 м вокруг игрока (радиус: экономная 70 м, стандарт 110 м, высокая 140 м; юбки против щелей). Чанки строятся порциями, чтобы не было рывков.
- Внешние горы за краем мира — отдельная сетка шага 12 м без скрытых треугольников внутри.
- Скорости, правила GDD и экономика B0 не менялись.

## Запустить

Preview pull request: адрес Vercel в PR #1. После слияния в `main` — [verion-game.vercel.app](https://verion-game.vercel.app/).

Автономная сборка: [vireon-verdana-b4.html](../../preview/vireon-verdana-b4.html) (генерируется `npm run build`, не править вручную).

```sh
npm ci
npm run dev
npm test
npm run build
VIREON_CHROMIUM_PATH=/путь/к/chromium npm run verify:browser
```

Управление прежнее: WASD/стрелки, мышь, Shift — бег, Space — прыжок, E — сканировать, M — карта, Esc — пауза. На телефоне — джойстик слева, свайп по сцене, кнопки справа.

## Проверка

- Восемь проверок контроллера (`npm test`): в том числе высоты в новом диапазоне, бег под уклон без отрыва от земли и проходимость пути к дальним местам.
- 25 браузерных проверок (`npm run verify:browser`, все проходят): загрузка, настройки с титула и из паузы, осмотр, движение, обзор, день/ночь, пауза, полный экран и его ошибки, качество, звук, покачивание, поле зрения, карта, мультитач, размеры кнопок, портрет, компактный экран, автономный файл без сети, 13 крупных планов и ночь, отсутствие ошибок консоли.
- Проверки идут в Chromium с **программным** WebGL 2: это подтверждает корректность, но **не производительность**. FPS B4 на физическом телефоне не измерен; мир стал больше, при проблемах начать с профиля «Экономная».
- `tools/scene-review.html` — стенд крупных планов (capsule, interior, cave, grass, valley, ice, ore, door, flank, berth, rack, copper, vista, canyon, crater; `&night` — ночь). Не входит в `dist/`.

## Ограничения

- Запечённые тени рассчитаны для одного положения солнца; смены времени суток с движущимся солнцем нет.
- Ровера, добычи и сохранения нет. Дальние места пока только для осмотра пешком.
- Размер мира 560×560 м — решение пользователя для визуального образца; итоговый масштаб участков для полной игры закрепляется в GDD отдельно.
