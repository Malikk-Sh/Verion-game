30.09.2026. Продолжение B2 по восьми Android-скриншотам Малика и запросу: качественнее и реалистичнее модели, более проработанный мир, продуманное первое ощущение, новый футуристичный интерфейс. Это по-прежнему **визуальный образец Three.js**; системы выживания, добычи и сохранения не подключены. B2 сохранён как история (`VERDANA_B2.md`, `preview/vireon-verdana-b2.html`).

## Запустить

Опубликованная версия после слияния в `main`: [verion-game.vercel.app](https://verion-game.vercel.app/). До слияния Vercel создаёт preview-адрес для pull request.

Автономная сборка: [vireon-verdana-b3.html](../../preview/vireon-verdana-b3.html) (генерируется `npm run build`, не править вручную).

```sh
npm ci
npm run dev
npm test
npm run build
VIREON_CHROMIUM_PATH=/путь/к/chromium npm run verify:browser
```

Управление прежнее: WASD/стрелки, мышь, Shift — бег, Space — прыжок, E — сканировать, M — карта, Esc — пауза. На телефоне — джойстик слева, свайп по сцене, кнопки справа.

## Модели и нагрузка

Вся геометрия и текстуры процедурные (TypeScript + canvas), **без GLB и внешних изображений**. Статические детали объединяются по материалам (`src/geometry.ts`), камешки и трава — InstancedMesh. Дальность камеры 1 400 м ради горизонта; видимость ограничивает туман. Для полной планеты по-прежнему нужны чанки/LOD. Крупные препятствия используют AABB, мелкий декор без точных коллизий.

## Проверка

- Шесть проверок контроллера (`npm test`).
- 22 браузерные проверки (`npm run verify:browser`, все проходят): загрузка, осмотр, движение, обзор, день/ночь, пауза, полный экран и его ошибки, переключатели качества и звука, карта, мультитач, размеры кнопок, портрет, компактный экран, автономный файл без сети, восемь крупных планов моделей, отсутствие ошибок консоли.
- Проверки проходят в Chromium с **программным** WebGL 2 (меньше 1 FPS) и профилем «Экономная». Это подтверждает корректность, но **не производительность**. FPS B3 на физическом телефоне не измерен; B3 тяжелее B2 (тени, более плотный рельеф, небо). При проблемах на телефоне начать с профиля «Экономная».
- `tools/scene-review.html` — стенд крупных планов (capsule, interior, cave, grass, valley, ice, ore, door; `&night` — ночь). Не входит в `dist/`.
