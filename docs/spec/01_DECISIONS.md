## 4. Явные редакционные изменения

1. Старое обещание «любой размер станции / сколько угодно баз» заменено свободой формы внутри технических бюджетов. Содержимое сверх бюджета не удаляется; новое строительство отклоняется с объяснением.
2. Исторический общий «самотёк» труб заменён управляемой сетью с помпами/газовым давлением, абстрагированным в скорость портов. Высота не требует расчёта гидравлики.
3. Посадочная мини-игра поверхности не копируется на орбитальную станцию: используется стыковка. Это закрытие отмеченного ранее конфликта, не отмена планетных посадок.
4. Кислород/температура помещения — агрегированная зона; её аварии не нарушают сохранность достигнутой планетарной терраформации.
5. Вода, запертая в достигнутой стадии водоёма, не изымается промышленностью. Водозабор работает из отдельного доступного запаса; это явная игровая граница необратимого ландшафта.
6. Бесконечный грунт глубинного экстрактора сохранён как уже принятое позднее допущение, не переименован в физически конечную залежь.
7. Пакеты старых предложений архивны по смыслу. Новые устройства/материалы из этих пакетов, которых нет в GDD 1.0, не считаются скрыто запланированными.
