# Интерфейс, управление, графика и звук

## 1. Мобильное управление

Landscape, первое лицо. Две зоны касания: левый джойстик перемещения и свободный свайп справа для камеры. Каждый pointerId закреплён за начатой зоной до отпускания; перенос пальца через границу не меняет назначение. UI не передаёт свой тап в сцену. Действия размером минимум 48 CSS px, отступ от safe-area устройства, масштаб интерфейса 90–130%.

| Элемент | Нажатие | Удержание / особенность |
| --- | --- | --- |
| Контекстная кнопка | Открыть машину/взять предмет/собрать урожай | Добыча при наведении на блок; показывает время и требуемый тир |
| Атака | Один удар с ограниченным доведением | Частота оружия не обходится частыми тапами |
| Прыжок | Прыжок | При когтях вместо него «Отцепить»; для jetpack появляется отдельная тяга |
| Пригнуться | Переключение стойки | Сохраняет состояние до отмены, не автоматически залезает в непроходимую щель |
| Бег | Переключение при наклоне джойстика | Останавливается при открытии инвентаря, расход голода показан |
| Быстрые слоты | Выбрать один из 6 | Удержание открывает замену ссылки, без дублирования предмета |
| Баллоны | Открыть панель двух установленных | Одним действием выбрать запасной, 2-секундная замена с кольцом прогресса |
| Пауза | Полная пауза | Экспорт, настройки, выход; не смешивать с инвентарём |

Поворот к портрету ставит игру на паузу и показывает «Поверните устройство»; после возврата требуется один тап «Продолжить». Изменение видимости страницы всегда пауза, возвращение не запускает время до подтверждения, чтобы игрок успел взяться за управление. При потере pointercancel все кнопки освобождаются.

## 2. HUD

Сверху: HP, сытость, два баллона (активный/резерв), пригодность среды, температура/давление вне диапазона. Численный расход и оставшееся время O₂ открываются тапом; точное время вычисляется из текущего источника, без ложной оценки при запасах комнаты.

Пороговые сигналы: O₂ 25%, 10%, переключение резервного, отсутствие газа; голод 25/10; опасная температура/давление; повреждение зоны и недостаток питания. Одновременно не больше двух центральных предупреждений, остальные в сворачиваемой ленте. Приоритет: удушье/среда → пролом/враг → питание → готовый крафт. Цвет дополнен пиктограммой и текстом; для красно-зелёной различимости есть альтернативная палитра. Звуковое предупреждение имеет cooldown 10 с, не повторяется на каждом тике.

Прицел показывает название блока/устройства и одну причину запрета: «Нужна стальная кирка», «Вне зоны раскопок», «Будущее русло», «Нет места для результата». Запрет не тратит ресурс. В интерфейсе не показываются названия классов, chunkId, IndexedDB или EU allocation; только понятные причины.

**Реализация S1.1 (по утверждённым макетам):** слева сверху три круговых индикатора (здоровье, сытость, O₂ в GU), под ними компактная задача; сверху по центру компас и метка цели; справа сверху кнопки «Костюм», «Рюкзак», «Карта», «День/Ночь», пауза; слева снизу джойстик; справа основная контекстная кнопка и под ней «Бег»/«Прыжок»; снизу по центру быстрый доступ = первая строка рюкзака. Центр экрана свободен. Инвентарь: снаряжение (карточка костюма + 2 баллона), сетка 6×4, карточка выбранного предмета с действиями; на телефоне перенос «выбрать → Переместить → цель» (пустая — перенос, занятая — обмен). Костюм — отдельный экран с четырьмя частями (D29). Здоровье и сытость в S1.1 только отображаются, их механика — этап «Выживание». Предметы используют 11 локальных прозрачных WebP-спрайтов 512×512; одни изображения используются в быстром доступе, рюкзаке, снаряжении и карточке предмета. Фигура костюма — композиция четырёх независимых растровых слоёв с подсветкой выбранной и слабым силуэтом снятой части. [Правила и происхождение спрайтов](../art/ui/UI_SPRITES.md).

## 3. Основные экраны и состояния

| Экран | Содержание | Существенные состояния |
| --- | --- | --- |
| Новый мир | Имя, seed, три стартовых района, стандартный режим | Seed можно скопировать; предупреждение о перезаписи существующего мира отсутствует, потому что создаётся новый slot |
| Инвентарь | Слоты, экипировка, быстрый крафт, разбивка стака | Полный, перенос/отмена, заполненный экземпляр; «Перенести всё» только при достаточном месте/с понятным остатком |
| Машина | Вход/выход, режим, прогресс, энергия, порты | Работает; нет сырья; нет энергии; выход заполнен; неподходящая среда; цель достигнута; повреждена |
| Строительство | Категория, прозрачный шаблон, поворот 90°, подтверждение | Зелёный/красный плюс текст причины; предварительный состав стоимости и будущая вода |
| Сети | Наложение направлений/типов портов | Несовместимый газ, замкнутый клапан, перегрузка кабеля, доступный резерв |
| Планета | Четыре карточки и местные условия | Атмосфера раскрывает P/O₂/tox, вода — закреплено/доступно, стабильность — отстающую цель |
| Технологии | Граф веток и узлы слияния | Видно точное условие; неизвестный чертёж и отсутствующий материал различаются |
| Планшет | Статическая справка, рецепты, карты/угрозы | Доступна офлайн после загрузки игры; никакого обязательного AI/внешнего API |
| Карта системы | Направления, тир, расход двух компонентов, груз | Жёстко блокирует только ракету/площадку/топливо/неоткрытый маршрут; снаряжение предупреждает |
| Предполётная проверка | Газ/топливо туда, обратные запасы, защита, площадка в грузе | Подтвердить риск можно; «Туда хватает, обратно нет» отдельной строкой |
| Смерть | Причина, сохранённое/потерянное, пригодные кровати/капсула | Непригодная кровать серым с причиной; выбранная точка не обещает бесплатную ракету |
| Сохранения | Миры, последнее успешное сохранение, экспорт/импорт, 3 ревизии | Запись/успех/ошибка места; импорт сначала проверяется и создаёт новый слот |
| Торговля | Цена/выход/запас/скидка | Подтверждение одной сделки, нет автоматической траты всего ресурса |

В интерфейсе станков в один момент виден один основной режим. Газ/жидкость имеют численную шкалу, кнопки +1/+10/всё; не требуется перетаскивать точные объёмы пальцем. Планшет объясняет каждый впервые полученный материал одной карточкой и указывает следующий полезный рецепт.

## 4. Первое обучение

Подсказки контекстны, максимум одна активная: 1) выйти и собрать траву; 2) посмотреть запас O₂ и вернуться к порту; 3) добыть руду; 4) сделать собственный кислород; 5) создать купол. Они основаны на достижениях и снимаются после действия, не линейная сюжетная миссия. Можно скрыть и вернуть в настройках. Планшет не требует постоянного сетевого соединения. Ключевой чертёж после steel отмечается областью; игрок всё ещё исследует вход.

## 5. Визуальная система

**Художественная спецификация A1:** [Вердана — три кадра, палитра, формы и свет](../art/VERDANA_ART_DIRECTION.md). Этап облика мира выполнен как концепт-пакет. После блокинга B1 реализован [визуальный образец B2](../prototypes/VERDANA_B2.md) с переработанными моделями и интерфейсом осмотра. Это ещё не HUD всех систем выживания. День и ночь сохраняют крупные ориентиры, ранняя база меняет только построенную игроком площадку и не означает готовую терраформацию. Изображения не заменяют размеры модулей/воздушных клеток из §03.

Ночная рассеянная подсветка для читаемости не является игровым защитным светом и не меняет спавн/солнечный урон врагов. Цвета мира и художественный свет не заменяют показания среды в HUD.

Low-poly с ясными силуэтами: Fe тёмно-серый, Cu оранжевый, Au жёлтый, велит бирюзовый, астрит пурпурный. Форма жил и пиктограмма различают ресурсы без цвета. Вердана — серо-зелёная и янтарная дымка; Нива — сине-серая, белый лёд; Пирра — тёмная порода и охра. Терраформирование меняет небо, растительность, видимость воды и звуковое окружение по стадиям.

Один атлас мира 2048², UI отдельно; повторяемые блоки и растения инстансируются. Прозрачные купола максимально простой материал, не многослойное преломление. Вода — плоскость с простым шейдером и береговой маской, без отражения всей сцены. Частицы выхода врага/пыли используют лимит пула, не обязательны для механики. Уход в темноту остаётся читаемым благодаря контурам прицела/фонаря, а не полной чёрной картинке.

## 6. Звук и доступность

Звуковые события: дыхание/резерв, удар/завершение добычи, старт/пауза машины, шлюз/утечка, выход врага, буря/предупреждение посадки, завершение стадии. В вакууме внешние звуки приглушены, контактные/костюмные сигналы слышны как игровая обратная связь. Одновременно максимум 16 пространственных источников, 4 приоритетных сигналов; остальные агрегируются по группе машин.

Настройки: громкость музыки/мира/предупреждений, чувствительность камеры, инверсия Y, левша, масштаб UI, снижение движения (камера без тряски/минимальный крен), альтернативные цвета, субтитры сигналов. Мерцание фонаря/аварии не обязательный способ передачи информации. Вибрация опциональна и не требуется для управления. Десктопные WASD/мышь нужны для разработки/резервного управления, отдельный десктопный релиз не обещан.
